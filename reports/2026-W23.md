# 具身智能技术洞察周报 (2026-06-01)

## 行业格局变化

### 主题趋势
1. **芯片技术突破与应用**：腾讯自研芯片“沧海”在MSU视频编码比赛中夺冠，V2芯片下半年量产，显示出芯片技术在视频编码领域的突破。
2. **新能源车市场调整与复苏**：Q1全球新能源车销量年减2%，中国市场调整，西欧复苏，表明新能源车市场正在经历结构性调整。
3. **AI技术加速融入各行业**：腾讯发布WorkBuddy海外版，AI桌面智能体拓展国际市场，以及OpenAI Gym API的重大变更，都显示出AI技术正加速融入各行各业。

### 重点厂商动作
- **腾讯**：自研芯片“沧海”夺冠，V2芯片下半年量产，电脑管家Mac版入局Mac生态，推出AI Agent安全防护，发布WorkBuddy海外版。
- **立讯精密**：收购闻泰科技部分业务违法，被罚款90万元。
- **广州数字科技集团**：注册资本增至10.8亿。
- **Triomics**：完成2200万美元B轮融资，专注于癌症中心AI应用。
- **HuggingFace**：发布Lerobot v0.5.0版本，更新lerobot至v0.4.3，增强机器人支持与功能。
- **OpenAI**：发布OpenAI Gym API v0.26.0，核心API重大变更，调查ChatGPT服务故障。

### 建议关注
1. **关注芯片技术的发展和应用**：特别是自研芯片在视频编码领域的应用。
2. **关注新能源车市场的动态**：尤其是中国市场和西欧市场的调整与复苏。
3. **关注AI技术在各行业的应用**：特别是AI桌面智能体和机器人操作技能的进步。
4. **关注政策标准的变化**：如抖音生活服务发布AIGC创作规范，央行行长强调科技创新再贷款政策应用。
5. **关注整机硬件的发展**：如四足机器人、电动智能船艇、AI眼镜等产品的研发和上市。
